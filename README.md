# Path-Visualizer
### 🧩 [Pathfinding Visualizer](https://github.com/your-username/pathfinder_project)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)
![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)

An interactive visualizer for classic pathfinding algorithms, built to explore how each algorithm explores a grid in real time.

- 🔍 **Algorithms:** Dijkstra's, BFS, and DFS
- 🌀 **Maze generation** for randomized obstacle courses
- 🎚️ **Adjustable animation speed** and **draggable start/end nodes**
  
## Tech Stack
HTML | CSS | JavaScript
